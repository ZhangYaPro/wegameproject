# 吉雪奇旅 · 三关试玩版

人物新模型、国旗袖标、第三关开阔雪谷与低障碍滑越见 [人物与雪谷改版说明.md](人物与雪谷改版说明.md)。

最新首页、左右选景、本地历史记录、长白岩谷与通关特写见 [首页与场景改版说明.md](首页与场景改版说明.md)。三关路线基础见 [三关赛道实现说明.md](三关赛道实现说明.md)。前期改动见 [千米雪旅实现说明.md](千米雪旅实现说明.md)，视频借鉴分析见 [视频参考与滑雪手感改进.md](视频参考与滑雪手感改进.md)。

这是横向 2.5D 滑雪可玩项目，目前有三个独立地图，并通过结算界面连接：雾凇江岸 1,018 米、北大湖挑战 1,518 米、长白岩谷 1,838 米。第一关长度与地形保留，后两关拥有独立坡形、障碍排列和背景模型。平路速度从 990 小幅提高到 1060 cm/s。旅行册、转体组合与上层支线等原设计功能尚未全部完成。

下坡小幅加速，上坡适当减速；橙色坡顶可飞跃。空格先起跳，空中连续按住约 0.6 秒后才开始空翻，并逐渐加快至每秒 300°；松手后选择距离回正更近的方向缓慢收势，不足半圈可转回、超过半圈继续转正。撤回未完成的旋转不会算作完整空翻。下落重力减小，增加腾空时间。正常落地结算动作分，轻微失衡只踉跄缓冲，明显翻倒才扣命。途中和空中可收集徽章与雾凇冰晶。镜头根据速度、腾空高度和预计落地点平滑调整。

赛道面向镜头的一侧改为连续延伸的积雪山坡，覆盖原先露出的垂直切面；九组文旅牌按新地形重新校正高度。

沿途新增长白、查干冬捕、延边与长春电车街景。白昼逐渐过渡到黄昏和雪夜，伴随飘雪及风声；入夜时路灯渐亮、背景燃放烟花。暂停会停止时间推进，重来会恢复白昼。

## 启动

双击项目根目录 `开始滑雪.cmd`，使用本机 `D:\UE_5.5` 启动独立游戏窗口。第一次加载可能需要编译着色器。

也可以保存并关闭旧的 Unreal 编辑器，重新打开 `Ski25D.uproject`。默认地图为 `/Game/Ski25D/Maps/SkiRimeMap`，点击“运行”。已打开的旧编辑器不会自动切换到新 C++ 模块；本次最终版本使用标准 `UnrealEditor-Ski25D.dll`。

项目根目录的 `试玩第一关.cmd`、`试玩第二关.cmd`、`试玩第三关.cmd` 可分别体验三个赛道。开始或结算界面按 1 / 2 / 3 也可选关。通关后按空格进入下一关，每关重新获得五条生命；第三关完成后回第一关。R 始终重置本关。

此启动方式依赖本机 Unreal 5.5，尚不是打包后可分发的 EXE。

| 操作 | 按键 |
|---|---|
| 开始 | 空格 / Enter |
| 起跳 | 空格，在障碍前金色标记附近按下 |
| 后空翻 | 腾空后连续按住空格约 0.6 秒；松手选择更近方向慢慢回正 |
| 刹车 | 按住 S，松开恢复自动滑行；主要在地面生效 |
| 暂停 / 继续 | Esc |
| 返回起点 | R |
| 选择章节 | 开始或结算界面按 1 / 2 / 3 |
| 前往下一关 | 通关结算后按空格 |

角色自动向右滑行；初始 5 条生命，撞到障碍或明显翻倒扣 1 条，生命耗尽结束；通过终点后显示结果。轻微歪斜不扣命，较大踉跄取消本次动作奖励。摔倒有屈膝、手臂失衡、翻倒、贴雪滑行与撑起动作，约 1.65 秒恢复，期间有 1.9 秒伤害保护，避免同一次事故重复扣命。

开始界面采用小角度缓慢环绕；生命耗尽后镜头缓慢推近并轻摆，场景带淡红色和轻微暗角，结算面板也变为暗红色。镜头始终留在场景正面。死亡时保持倒地姿态；重开会清除色调、恢复相机和人物。

## 当前内容与文件

- `Source/Ski25D/SkiRunnerCharacter.cpp`：角色、镜头、输入、跳跃、碰撞判定和进度。
- `Source/Ski25D/SkiRunnerTricks.cpp`：后空翻、落点预测、收集奖励。
- `Source/Ski25D/SkiRunnerPresentation.cpp`：肢体姿态、摔倒起身、菜单与死亡运镜。
- `Source/Ski25D/SkiJourneyAtmosphere.cpp`：昼夜、路灯、风雪、风声和烟花。
- `Source/Ski25D/SkiSampleTrail.cpp`：连续雪道、雾凇、松林、江面、木屋、路标和障碍。
- `Source/Ski25D/SkiSampleGameMode.cpp`：游戏入口、中文 HUD 和状态面板。
- `Content/Ski25D/Maps/SkiRimeMap.umap`、`SkiBeidahuMap.umap`、`SkiChangbaiMap.umap`：三个独立赛道地图。
- `Source/Ski25D/SkiTrailChapters.cpp`：北大湖、长白林海的独立地形、背景、设施和章节参数。
- `Scripts/build_three_courses.py`：生成三个独立地图和标牌。
- `Scripts/make_art.py`：原创标牌与雪面纹理源文件生成。
- `Scripts/build_sample.py`：Unreal 编辑器资产与地图生成脚本。重跑会重建样板地图，不应在人工修改该地图后直接执行。
- `ContentSource/SkiSample`：标牌和材质纹理源图。

原始 ThirdPersonMap 和原模板角色代码保留。平缓样板的地图与源码备份位于 `Backup/BeforeChallenge`。样板使用引擎角色移动组件与连续雪道碰撞，不自行开发滑雪物理引擎。新的地形高度只在 C++ 中定义，地图生成脚本通过反射调用同一函数，保证标牌、出生点与雪道高度一致。

## 自动检查

三关固定 60 Hz 时间步的自动通关及连续换关检查已通过：第一关 97.24 秒，第二关 144.34 秒，第三关 175.80 秒，共约 6 分 57 秒（不含菜单、加载和暂停）。每关剩余 5 条生命、成功空翻 9 次。结果分别保存在 `Saved/SkiQA/chapter_1_smoke.json`、`chapter_2_smoke.json`、`chapter_3_smoke.json`。这是物理与玩法回归检查，不是运行帧率承诺；画面另通过各关实机渲染截图核对。

引擎带 `-SkiSmokeTest` 运行样板地图会自动滑行和起跳，输出 `Saved/SkiQA` 截图与完成测试结果。该检查覆盖路线、基础跳跃、生命和 2.5D 平面约束，不替代手动键盘试玩和最终性能测试。

千米版验收覆盖完整通关、生命、腾空、动态镜头、刹车、连续后空翻、松键收势、地面与空中拾取及侧向平面约束；另用 `-SkiNoInputTest` 检查无操作失败。结果分别记录在 `Saved/SkiQA/smoke.json` 和 `Saved/SkiQA/no_input.json`。环境检查记录在 `Saved/SkiQA/environment.json`。

第一关地形沿用已验证的起伏坡段版：总长度 1,018 米，九组标牌净空检查通过。本轮平路巡航目标提高到 1060 cm/s，下坡小幅增加，控制速度上限 1410 cm/s。旧版地形记录见 `Saved/SkiQA/rolling_course.json`；旧版速度下的历史试玩记录见 `Saved/SkiQA/rolling_smoke.json`。

动态界面检查使用 `-SkiPresentationTest`：记录开始界面运镜、随后无操作碰撞耗尽五条命、最后记录死亡缩放和色调。结果见 `Saved/SkiQA/presentation.json`。实际截图包括 `MenuEarly.png`、`MenuOrbit.png`、`DeathImpact.png`、`DeathOrbit.png`；摔倒分阶段截图为 `FallImpact.png`、`FallSlide.png`、`FallGetUp.png`。

历史单关就近回正与动态界面版：完整自动试玩通过，105.06 秒通关，主动摔倒一次后剩余 4/5 生命，成功空翻 6 次。状态检查扩展为 28 项，覆盖两种回正方向、撤回半圈不加分、宽容落地、摔倒阶段与重开复位。历史试玩记录见 `Saved/SkiQA/forgiving_smoke.json`；状态检查继续由 `landing_checks.json` 记录。

本机集成显卡下仍需进一步优化，不能视为已经达到比赛最终性能目标。启动入口默认 1280×720；后续需要在参赛设备上验证帧率。当前空翻使用程序动画、风声使用原创合成音频，尚未包含完整音效组合和独立安装包。
